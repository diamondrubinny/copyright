# תנאי שימוש — מָגֵן (טיוטה)

> ⚠️ טיוטה טכנית. דורשת בדיקה ואישור של עו"ד לפני פרסום. אינה ייעוץ משפטי.

עדכון אחרון: 2026-10-22

## 1. השירות
מָגֵן מאפשר לבדוק אם סיסמה או כתובת אימייל הופיעו בדליפות מידע ידועות, לצורכי מודעות והגנה עצמית.

## 2. שימוש מותר
- מותר לבדוק סיסמאות וכתובות אימייל **שלך** או שאתה מורשה לבדוק.
- אין להשתמש בשירות כדי לתקוף, להטריד או לפגוע בפרטיות של אחרים.
- אין לבצע שימוש אוטומטי/המוני החורג מהגבלות הקצב של השירות.

## 3. היעדר אחריות
- תוצאת "לא נמצא" אינה ערובה לכך שהמידע מאובטח — ייתכנו דליפות שאינן ידועות.
- השירות ניתן "כפי שהוא" (AS IS), ללא התחייבות לזמינות או לדיוק מלא.
- מָגֵן אינו תחליף למנהל סיסמאות, לאימות דו-שלבי או לייעוץ אבטחה מקצועי.

## 4. פרטיות
